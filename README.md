# Auris — Environmental Audio Classification

**Auris** is a collaborative final project exploring environmental audio classification, dataset curation, and desktop audio monitoring.

## What the project developed

- A workflow for preparing audio data, annotations, and traceable experiment records.
- EfficientAT DyMN10-based models for 13-class Softmax classification and a separate masked-label Sigmoid research task.
- Desktop tools for microphone monitoring, audio inspection, and selecting a model for inference.
- Evaluation and research records that distinguish development measurements from deployment claims.

## Selected research snapshot

A documented **4 October 2026 development run** reached **97.03% Softmax validation accuracy**. A separate masked-label Sigmoid run reached **96.98% validation mAP**. These results came from different tasks and supervised populations; they are not a direct comparison, an unseen test result, or a field-performance guarantee.

Auris was developed collaboratively. This overview describes the shared project without assigning individual ownership of the research or dataset decisions.
